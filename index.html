Visão Geral & Autenticação

Todas as requisições para a API devem ser feitas para a URL base do seu servidor enviando o token de acesso no cabeçalho HTTP Authorization.

Authorization: Bearer dst_live_seu_token_aqui
GET /api.php/products

Retorna a lista completa de todos os produtos cadastrados com seus respectivos códigos de barras, preços e estoque.

GET /api.php/products?barcode=7891234567890

Consulta direta ideal para leitores de código de barras. Retorna o produto exato correspondente ao EAN scaneado.

POST /api.php/products

Cadastra um novo produto no sistema via API remota.
